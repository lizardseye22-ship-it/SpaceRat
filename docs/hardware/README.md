# SpaceRat — железо

6DOF-манипулятор на датчиках Холла: Blue Pill (STM32F103C8T6), 8 × DRV5055 в 4 парах,
энкодер EC11 и 5 кнопок хоткеев. Питание от USB.

## Распиновка Blue Pill

| Пин | Назначение |
|---|---|
| 3.3 / G | Питание датчиков (только 3.3 В, не 5 В) |
| PA0–PA7 | OUT датчиков U1–U8 (АЦП, по очереди с усреднением) |
| PB6 / PB7 | Энкодер A / B (TIM4, режим энкодера) |
| PB5 | Кнопка энкодера |
| PB8, PB12–PB15 | Кнопки SW1–SW5 (внутренние pull-up) |

Не использовать: PB2 (BOOT1), PB3/PB4/PA15 (JTAG), PA11/PA12 (USB), PA13/PA14 (SWD).

Кнопки → кнопки SpaceMouse Pro: SW1–SW4 → 1–4, SW5 → Fit, энкодер вправо/влево → T/R,
нажатие энкодера → F (щелчок = «нажатие» 30 мс). Подробно: [`../../firmware/README.md`](../../firmware/README.md).

## Механика (стартовые размеры)

- 4 пары на окружности R ≈ 25 мм (допустимо 22–30), через 90°.
- Линия A–B каждой пары — **по касательной**, все пары в одном направлении обхода.
- Шаг датчиков в паре ≈ 9 мм (≈ диаметр магнита).
- Магнит над серединой пары, все одним полюсом вниз.
- Зазор магнит — корпус датчика 5–6 мм для A3 (7–9 мм для A2, 3–4 мм для A4);
  заложить регулировку.
- Ход ручки ~±1.5 мм, несколько градусов наклона.
- Рядом с датчиками — без стали (винты пластик/латунь/нержавейка A2).

Проверка: OUT в покое ~2.2–2.5 В, при полном нажатии не выше ~3.0 В.

## Оси

Для пары i: Sᵢ = Aᵢ + Bᵢ, Dᵢ = Aᵢ − Bᵢ (после вычитания нулей).

```
TZ = S0 + S1 + S2 + S3      RZ = D0 + D1 + D2 + D3
RX = S1 − S3                TX = D3 − D1
RY = S2 − S0                TY = D0 − D2
```

Знаки подбираются по факту.
