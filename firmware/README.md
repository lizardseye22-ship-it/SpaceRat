# SpaceRat — прошивка (Embassy, Blue Pill)

Прошивка для STM32F103C8 (Blue Pill) на Rust + [Embassy](https://embassy.dev).
Устройство представляется как **3Dconnexion SpaceMouse Pro Wireless (cabled)**
(VID 0x256F, PID 0xC631) и работает с драйвером **3DxWare под Windows**.

- Железо и распиновка: [`../docs/hardware`](../docs/hardware)
- USB-протокол: [`../docs/firmware/usb-hid-protocol.md`](../docs/firmware/usb-hid-protocol.md)

## Что делает

| Задача | Как |
|---|---|
| 8 датчиков Холла, PA0–PA7 | АЦП, 8 выборок на канал, цикл 2 мс, IIR-фильтр |
| Калибровка нуля | при включении: 0.5 с пауза, затем усреднение ~0.3 с. **Ручку в это время не трогать** |
| Дрейф нуля | медленная подстройка, если ручку не трогают дольше 1 с |
| 6 осей | суммы/разности пар → матрица калибровки (убирает взаимное влияние осей) → мёртвая зона, усиление, ограничение ±350 |
| Калибровка | SW1 + SW5 при включении → мастер по шагам с подсказками на кольце, результат во flash |
| Кольцо WS2812, PA8 | TIM1 + DMA, 50 кадров/с: подсказки калибровки, статусы, направление движения |
| 5 кнопок, PB8 PB12–PB15 | внутренние pull-up, антидребезг 5 мс |
| Энкодер EC11, PB6/PB7 + кнопка PB5 | аппаратный декодер TIM4 (режим энкодера, входной фильтр), щелчок → «нажатие» 30 мс + пауза 30 мс |
| USB HID | отчёт раз в 8 мс: оси (Report 1), пока есть движение, + 3 нулевых; кнопки (Report 3) при изменении; светодиод (Report 4) принимается и игнорируется |

Кнопки → кнопки SpaceMouse Pro (в 3DxWare им назначается что угодно):

| Вход | Кнопка SpaceMouse Pro |
|---|---|
| SW1–SW4 | 1–4 |
| SW5 | Fit |
| Энкодер вправо / влево | Top [T] / Right [R] |
| Нажатие энкодера | Front [F] |

Таймеры: **TIM3** — системное время Embassy, **TIM4** — энкодер, **TIM1** — кольцо WS2812 (DMA1 канал 5).

## Сборка

Нужен Rust (https://rustup.rs). Цель `thumbv7m-none-eabi` поставится сама
по `rust-toolchain.toml`.

```sh
cd firmware
cargo build --release
```

Результат: `target/thumbv7m-none-eabi/release/spacerat` (ELF). Размер ~52 КБ flash из 63 (последняя страница 1 КБ — под калибровку), ~6 КБ RAM.

## Прошивка

**ST-Link + probe-rs** (рекомендуется, заодно виден лог):

```sh
cargo install probe-rs-tools
cargo run --release          # прошьёт и покажет лог defmt
```

**ST-Link + STM32CubeProgrammer / st-flash** (нужен .bin):

```sh
cargo install cargo-binutils && rustup component add llvm-tools
cargo objcopy --release -- -O binary spacerat.bin
# STM32CubeProgrammer: адрес 0x08000000
# или: st-flash write spacerat.bin 0x8000000
```

Джамперы BOOT0/BOOT1 на Blue Pill — в 0 (обычный режим).

## Первое включение

1. Подключить USB, **не трогать ручку ~1 с** (калибровка нуля) — на кольце бегает белая точка.
2. В диспетчере устройств Windows появится HID-устройство, 3DxWare покажет
   SpaceMouse Pro Wireless.
3. Пока мышь не откалибрована, со стороны пользователя тускло «дышит» янтарный — пройдите калибровку.
4. В 3DxWare проверить оси (окно Test/Calibrate) и назначить кнопки.

## Калибровка

Делается один раз после сборки и после изменений механики (пружины, зазор, магниты).
Результат хранится во flash и работает без ПК.

1. **Зажать SW1 + SW5 и подключить USB**, затем отпустить кнопки и не трогать ручку ~1 с.
2. **6 движений по порядку.** Каждое — довести ручку до упора и держать неподвижно
   ~1 с, пока цвет подсказки не станет белым. Потом отпустить в центр
   (кольцо зелёное — записано) и делать следующее.

   | Шаг | Движение | Подсказка на кольце | Белых точек у пользователя |
   |---|---|---|---|
   | 1 | сдвиг **вправо** | зелёный лепесток справа | 1 |
   | 2 | сдвиг **от себя** | зелёный лепесток впереди | 2 |
   | 3 | **нажать вниз** | всё кольцо пульсирует зелёным | 3 |
   | 4 | **наклон от себя** | фиолетовый лепесток впереди | 4 |
   | 5 | **наклон вправо** | фиолетовый лепесток справа | 5 |
   | 6 | **поворот по часовой** | зелёная точка бежит по часовой | 6 |

   Мигает **красным** — это движение уже было (перепутан порядок): отпустите и повторите шаг.
3. **Радуга: 10 секунд крутить ручку во все стороны до упора** — уточняется
   масштаб каждой оси отдельно в «+» и «−».
4. **Белое заполнение: отпустить и не трогать ~2 с** — замер шума для мёртвых зон.
5. **Зелёное мигание** — сохранено, мышь работает дальше. **Красное** — не удалось
   (движения не различаются или ошибка flash): остаются прежние значения, повторите.

Что вычисляется: матрица 6×6, которая превращает сырые оси в «чистые»
(каждое движение даёт полный ход только по своей оси — перекрёстное влияние
убирается), масштаб по направлениям и мёртвые зоны.

После калибровки проверьте направления в 3DxWare: «+» каждой оси — это движение
из таблицы выше. Если программа ждёт обратного знака, переверните ось в
`INVERT` в `src/config.rs` — калибровку повторять не нужно.

### Кольцо в обычной работе

| Что видно | Значение |
|---|---|
| бегущая белая точка | калибровка нуля при включении — не трогать |
| тусклое янтарное «дыхание» со стороны пользователя | мышь не откалибрована |
| голубой лепесток | сдвиг ручки, в его сторону |
| фиолетовый лепесток | наклон ручки, в его сторону |
| весь круг синий / янтарный | нажатие вниз / подъём |
| зелёная дуга от переднего края | поворот, длина = сила |

Подсветку движения можно выключить: `LED_SHOW_MOTION = false`.

## Настройка

Все параметры — в [`src/config.rs`](src/config.rs):

| Параметр | Что |
|---|---|
| `INVERT` | инверсия каждой оси — подобрать знаки под 3DxWare (действует и после калибровки) |
| `GAIN`, `DEADZONE` | усиление и мёртвая зона — **только пока нет калибровки** |
| `CAL_*` | параметры мастера калибровки: время удержания, порог движения и т.д. |
| `LED_COUNT` | число светодиодов в кольце |
| `LED_FIRST_ANGLE_DEG`, `LED_CLOCKWISE` | где на кольце светодиод №0 (0° = вправо, 90° = от себя) и в какую сторону нумерация |
| `LED_BRIGHTNESS` | яркость 0–255 (ограничивает и ток) |
| `LED_SHOW_MOTION` | показывать направление движения в обычной работе |
| `BUTTON_BITS`, `ENC_*_BIT` | какая кнопка SpaceMouse Pro на каком входе |
| `ENC_STEPS_PER_DETENT`, `ENC_REVERSE` | отсчётов TIM4 на щелчок (EC11: 4) и направление энкодера |
| `REPORT_PERIOD_MS` | период HID-отчётов (8 мс = как Space Navigator) |

Сырые значения для настройки видны в логе при `DEFMT_LOG=debug`:

```sh
DEFMT_LOG=debug cargo run --release
# raw [..8 датчиков..] axes_raw [..6 осей до усиления..] hid [..что уходит в ПК..]
```

Обычно достаточно калибровки кнопками. Ручная настройка `GAIN`/`DEADZONE` нужна,
только если калибровку не проходить.

**Как выставить кольцо:** включите мышь и сдвиньте ручку вправо — голубой
лепесток должен гореть справа. Если он в другом месте, поправьте
`LED_FIRST_ANGLE_DEG`; если при сдвиге от себя лепесток уходит к пользователю —
поменяйте `LED_CLOCKWISE`.
В логе также есть предупреждение, если датчик близок к рельсу (магнит слишком близко).

## Проверка логики на ПК

Энкодер, антидребезг, формулы осей, мастер калибровки (на синтетической мыши
с перекрёстным влиянием осей), хранение во flash и отрисовка кольца покрыты
тестами, которые идут на ПК без платы:

```sh
# из корня репозитория
cd tests/firmware_logic
cargo test
```

## Структура

| Файл | Что |
|---|---|
| `src/main.rs` | тактирование, USB, задачи: датчики и калибровка, кнопки, отчёты, кольцо |
| `memory.x` | карта памяти: 63 КБ программе, последняя страница — калибровке |
| `src/config.rs` | все настройки |
| `src/hid.rs` | HID-дескриптор (92 байта), сборка отчётов, ответы на запросы класса |
| `src/sensors.rs` | ноль, фильтр, пары → сырые оси, подстройка дрейфа |
| `src/calib.rs` | данные калибровки и их применение, мастер калибровки, CRC |
| `src/storage.rs` | калибровка во flash (последняя страница) |
| `src/led.rs` | кольцо WS2812: картинки для состояний, упаковка кадра для DMA |
| `src/input.rs` | антидребезг, щелчки по счётчику TIM4, щелчки → нажатия |
